## Before publishing

On a Mac that has not used Stillterm, download and install the final disk image
without changing Gatekeeper or quarantine. Check preview, Dense Matrix, ordered
phrases, theme switching, sleep/wake, dismissal, and uninstall. Record the Mac
model and macOS version, along with any issues.

Once that check passes, publish the existing draft without replacing the verified
image. Update the README and website with the actual public download URL. Do not
claim physical Intel or long-session coverage without those separate checks.
Windows distribution remains separate until the latest features are manually tested.
